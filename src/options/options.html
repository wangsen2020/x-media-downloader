No downloads yet. Open X, find a video, and hit Download.

Used by the popup and the in-timeline Download button. X serves a few fixed renditions per video; “closest below” picks the best one that does not exceed your target.

Tokens: {user} {text} {datetime} {date} {time} {id} {quality} {height} {bitrate} {index} {text} is the first few words of the tweet; {datetime}/{date}/{time} use the tweet's own post time. .mp4 is added automatically; / nests subfolders. The default ({user}_{text}_{datetime}_{id}) is always unique — the tweet id prevents any collision.

Chrome extensions can only write inside the browser’s Downloads folder. A relative subfolder is the closest thing to “choose a path”. Leave blank to save straight into Downloads. To pick a location every time, turn on the option below. Tokens: {user} {id} {text} {date} {time} {datetime} {quality} {height} {bitrate} {index} {count} Use / to nest folders.
