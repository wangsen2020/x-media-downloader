X(옛 트위터)의 동영상, GIF, 이미지를 클릭 한 번으로 저장하세요. 화질도 저장 위치도 직접 고르고, 저장한 파일은 전부 기록으로 남습니다.

휴대폰에서는 저장할 수 없는 영상도 클릭 한 번으로

X 모바일 앱에서는 많은 영상에 '다운로드'나 '저장' 버튼이 아예 없습니다. 볼 수는 있어도 간직할 수는 없죠. 같은 게시물을 컴퓨터에서 열면 이 확장 프로그램이 '마음에 들어요'와 '북마크' 옆에 다운로드 아이콘을 추가합니다. 브라우저에서 재생되는 영상이라면 클릭 한 번으로 일반 MP4 파일로, 가장 높은 화질로 저장됩니다.

프로필 동영상을 한꺼번에 저장

누군가의 프로필에서 '동영상' 탭을 연 다음 확장 프로그램 아이콘을 클릭하고 '@사용자의 미디어 모두 다운로드'를 선택하세요. 그 탭의 동영상과 GIF가 모두 해당 계정 이름의 폴더에 저장되고, 페이지 맨 위의 작은 패널에 진행 상황이 표시되며 일시 중지와 중지 버튼이 있습니다.

스크래퍼가 아니라 사람이 둘러보는 속도로 작동합니다. 2–4초마다 화면 하나, 동시에 최대 3개까지 다운로드하며, X가 요청이 너무 많다고 알리는 순간 멈춥니다. 페이지를 스크롤할 때 X가 이미 불러오는 내용만 읽으며, 확장 프로그램이 자체적으로 X를 호출하지는 않습니다. 한 번에 최대 500개 파일. 멈춘 곳에서 이어가려면 다시 실행하면 되고, 이미 있는 파일은 건너뜁니다.

왜 이 확장 프로그램인가

대부분의 X 영상 다운로더는 버튼 하나가 전부입니다. 화질은 알아서 정해지고, 파일은 video.mp4 같은 이름으로 다운로드 폴더에 던져지며, 다음에 저장한 파일이 이전 파일을 덮어씁니다. 이 확장 프로그램은 바로 그 세 가지를 해결하려고 만들었습니다.

주요 기능

• 동영상, GIF, 이미지 모두 지원 — 미디어가 있는 게시물이면 액션 바에 다운로드 아이콘이 나타납니다. X 자체 아이콘에 맞춘 디자인과 크기라 어색하게 튀지 않습니다. 이미지 게시물과 링크 미리보기 카드도 지원합니다. 동영상과 사진이 함께 있는 게시물은 클릭 한 번에 모두 저장됩니다.

• 화질 선택 — 기본값(최고 / 1080p / 720p / 480p / 360p / 최저)을 지정하면 그 한도를 넘지 않는 최상의 화질을 항상 선택합니다. 아이콘을 마우스 오른쪽 버튼으로 클릭하면 X가 해당 게시물에 실제로 제공한 화질 목록에서 그때그때 고를 수 있습니다.

• 중복 복사본 없음 — 이 확장 프로그램은 이미 저장한 내용을 기억하며, 같은 영상이 다른 사람의 리포스트에 나와도 알아봅니다. 다시 클릭하면 "(1)" 복사본을 만들지 않고 "이미 다운로드함"이라고 알려 주며, 한 번 더 클릭하면 그래도 다운로드합니다. 파일을 삭제한 경우에는 그냥 다시 받습니다.

• 계정마다 폴더 하나 — 파일은 기본적으로 Downloads/X Media Downloader/<계정>/에 저장되므로 계정별 미디어가 한곳에 모입니다. 폴더 이름을 바꾸거나, 파일 이름 변수를 폴더에 쓰거나, "매번 저장 위치 묻기"를 켜서 파일마다 시스템의 다른 이름으로 저장 대화상자를 띄울 수 있습니다.

• 절대 겹치지 않는 파일 이름 — 기본 형식은 {user}_{text}_{datetime}_{id}입니다. 작성자, 게시물 앞부분 문구, 게시물 자체의 작성 시각, 그리고 게시물 ID. 내용을 알아보기 쉽고, 시간순 정렬이 되며, 실수로 덮어쓸 일이 없습니다.

• 전체 다운로드 기록 — 모든 파일이 옵션 페이지에 썸네일, 계정, 화질, 용량, 날짜, 상태와 함께 기록됩니다. 검색하고, 다시 받고, 파일이 있는 폴더를 열고, 기록 전체를 JSON으로 내보낼 수 있습니다. 프로필 다운로드는 따로 볼 수 있습니다.

• 이미지가 여러 장인 게시물은 모든 사진을 원본 해상도로 _1부터 _4까지 번호를 붙여 저장합니다.

• 사용 중인 언어로 — 전체 인터페이스가 브라우저 언어를 따릅니다: 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어(스페인 및 라틴아메리카), 브라질 포르투갈어와 아랍어.

개인정보

계정 불필요, 서버 없음, 분석 없음, 추적 없음. 모든 동작은 브라우저 안에서 로컬로 이루어지며 다운로드 기록은 절대 기기 밖으로 나가지 않습니다. 네트워크 요청은 요청한 미디어를 가져오기 위한 X 자체 도메인으로만 전송됩니다.
