一鍵下載 X（原推特）上的任意影片、GIF 動圖或圖片——清晰度你選，儲存目錄你定，每次下載都有完整紀錄可查。

手機上存不了的影片，這裡一鍵就能存

在 X 手機 App 裡，很多影片根本沒有「下載」或「儲存」按鈕——能看，但存不下來。在電腦上打開同一則貼文，這個擴充功能會在「喜歡」和「書籤」旁邊加一個下載圖示。只要影片能在瀏覽器裡播放，點一下就能存成普通的 MP4 檔案，預設就是最高清晰度。

整個主頁的影片，一次存下來

打開某個帳號主頁的「影片」分頁，點擊擴充功能圖示，選擇「下載 @使用者 的全部媒體」。頁面上的所有影片和 GIF 都會存進以這個帳號命名的資料夾，頁面頂部有一個小面板顯示進度，可以暫停或停止。

它的節奏像一個人在翻頁，而不是爬蟲：每 2–4 秒捲動一屏，同時最多下載 3 個檔案，X 一提示請求過多就立刻停下。它只讀取頁面捲動時 X 本來就會載入的內容，從不自己去呼叫 X 的介面。每次最多 500 個檔案，再執行一次就從上次停下的地方繼續，已經下載過的會自動跳過。

為什麼是這一個

大多數 X 影片下載擴充功能只給你一個按鈕和一次賭博：清晰度由它決定，檔案一股腦丟進 Downloads 資料夾，名字叫 video.mp4，下一次下載直接把上一次覆蓋掉。這個擴充功能就是為了解決這三件事而寫的。

功能

• 影片、GIF、圖片全支援 —— 只要貼文裡有媒體，操作列就會出現一個下載圖示，樣式和尺寸完全對齊 X 自帶的圖示，不會顯得突兀。圖片貼和連結預覽卡片同樣支援。同時帶影片和圖片的貼文，點一下全部存下。

• 清晰度自己挑 —— 設定一個預設檔（最高 / 1080p / 720p / 480p / 360p / 最低），擴充功能始終選取不超過該檔位的最佳畫質。右鍵點擊圖示，可以從 X 為這則貼文實際提供的所有版本裡臨時挑一個。

• 不再存出重複檔案 —— 擴充功能會記住你已經存過什麼，同一個影片被別人轉發到其他貼文裡也認得出來。再點一次會提示「已經下載過」，而不是多出一個「(1)」副本；確實想再存一份，再點一下就行。如果檔案已經被你刪掉，會照常重新下載。

• 按帳號分資料夾 —— 預設存到 Downloads/X Media Downloader/<帳號>/，每個帳號的媒體放在一起，好找。資料夾名可以改，也能用檔名裡的各種變數；或者打開「每次詢問儲存位置」，每個檔案都彈出系統的另存新檔對話框。

• 檔名永不重複 —— 預設範本是 {user}_{text}_{datetime}_{id}：作者、正文開頭幾個詞、貼文自身的時間戳和 ID。一看就知道是什麼，可以按時間排序，也不可能誤覆蓋。

• 完整下載歷史 —— 每個檔案都記錄在選項頁裡，含縮圖、帳號、清晰度、大小、日期和狀態。可搜尋、可重新下載、可在資料夾中定位，也可以把整份紀錄匯出為 JSON。整個主頁的下載可以單獨篩選查看。

• 多圖貼會把每張圖都按原始解析度下載，自動編號 _1 到 _4。

• 介面說你的語言 —— 整個介面跟隨瀏覽器語言自動切換：繁體中文、簡體中文、English、日本語、한국어、西班牙語（西班牙和拉美）、巴西葡萄牙語和阿拉伯語。

隱私

不需要帳號，沒有伺服器，沒有統計，沒有追蹤。一切都在你的瀏覽器本機執行，下載歷史永遠不會離開你的電腦。唯一的網路請求是向 X 自己的網域解析你要下載的那個媒體檔案。
