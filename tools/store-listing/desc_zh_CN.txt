一键下载 X（原推特）上的任意视频、GIF 动图或图片——清晰度你选，保存目录你定，每次下载都有完整记录可查。

手机上存不了的视频，这里一键就能存

在 X 手机 App 里，很多视频根本没有“下载”或“保存”按钮——能看，但存不下来。在电脑上打开同一条帖子，这个扩展会在“点赞”和“书签”旁边加一个下载图标。只要视频能在浏览器里播放，点一下就能存成普通的 MP4 文件，默认就是最高清晰度。

整个主页的视频，一次存下来

打开某个账号主页的“视频”标签页，点击扩展图标，选择“下载 @用户 的全部媒体”。页面上的所有视频和 GIF 都会存进以这个账号命名的文件夹，页面顶部有一个小面板显示进度，可以暂停或停止。

它的节奏像一个人在翻页，而不是爬虫：每 2–4 秒滚动一屏，同时最多下载 3 个文件，X 一提示请求过多就立刻停下。它只读取页面滚动时 X 本来就会加载的内容，从不自己去调用 X 的接口。每次最多 500 个文件，再运行一次就从上次停下的地方继续，已经下载过的会自动跳过。

为什么是这一个

大多数 X 视频下载插件只给你一个按钮和一次赌博：清晰度由它决定，文件一股脑丢进 Downloads 文件夹，名字叫 video.mp4，下一次下载直接把上一次覆盖掉。这个扩展就是为了解决这三件事而写的。

功能

• 视频、GIF、图片全支持 —— 只要帖子里有媒体，操作栏就会出现一个下载图标，样式和尺寸完全对齐 X 自带的图标，不会显得突兀。图片帖和链接预览卡片同样支持。同时带视频和图片的帖子，点一下全部存下。

• 清晰度自己挑 —— 设定一个默认档（最高 / 1080p / 720p / 480p / 360p / 最低），扩展始终选取不超过该档位的最佳画质。右键点击图标，可以从 X 为这条帖子实际提供的所有版本里临时挑一个。

• 不再存出重复文件 —— 扩展会记住你已经存过什么，同一个视频被别人转发到其他帖子里也认得出来。再点一次会提示“已经下载过”，而不是多出一个“(1)”副本；确实想再存一份，再点一下就行。如果文件已经被你删掉，会照常重新下载。

• 按账号分文件夹 —— 默认存到 Downloads/X Media Downloader/<账号>/，每个账号的媒体放在一起，好找。文件夹名可以改，也能用文件名里的各种变量；或者打开“每次询问保存位置”，每个文件都弹出系统的另存为对话框。

• 文件名永不重复 —— 默认模板是 {user}_{text}_{datetime}_{id}：作者、正文开头几个词、帖子自身的时间戳和 ID。一看就知道是什么，可以按时间排序，也不可能误覆盖。

• 完整下载历史 —— 每个文件都记录在选项页里，含缩略图、账号、清晰度、大小、日期和状态。可搜索、可重新下载、可在文件夹中定位，也可以把整份记录导出为 JSON。整个主页的下载可以单独筛选查看。

• 多图帖会把每张图都按原始分辨率下载，自动编号 _1 到 _4。

• 界面说你的语言 —— 整个界面跟随浏览器语言自动切换：简体中文、繁體中文、English、日本語、한국어、西班牙语（西班牙和拉美）、巴西葡萄牙语和阿拉伯语。

隐私

不需要账号，没有服务器，没有统计，没有追踪。一切都在你的浏览器本地运行，下载历史永远不会离开你的电脑。唯一的网络请求是向 X 自己的域名解析你要下载的那个媒体文件。
