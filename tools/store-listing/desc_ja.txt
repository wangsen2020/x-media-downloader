X（旧 Twitter）の動画・GIF・画像をワンクリックで保存。画質も保存先も自分で選べて、保存したものはすべて履歴に残ります。

スマホでは保存できない動画も、ここならワンクリック

X のスマホアプリでは、多くの動画に「ダウンロード」や「保存」のボタンがありません。見ることはできても、手元には残せません。同じ投稿をパソコンで開けば、この拡張機能が「いいね」や「ブックマーク」の隣にダウンロードアイコンを追加します。ブラウザで再生できる動画なら、ワンクリックで通常の MP4 ファイルとして、最高画質で保存できます。

プロフィールの動画をまとめて保存

誰かのプロフィールの「動画」タブを開き、拡張機能のアイコンをクリックして「@ユーザー のメディアをすべてダウンロード」を選びます。そこにある動画と GIF がすべて、そのアカウント名のフォルダに保存され、ページ上部の小さなパネルに進捗が表示されます。一時停止と停止のボタンもあります。

ペースはスクレイパーではなく、人が閲覧しているときと同じです。2–4 秒ごとに 1 画面、同時ダウンロードは最大 3 件で、X がリクエスト過多と知らせた瞬間に止まります。読み取るのは、ページをスクロールしたときに X がもともと読み込む内容だけです。拡張機能から X を独自に呼び出すことはありません。1 回あたり最大 500 ファイル。止まったところから続けるにはもう一度実行すればよく、すでに保存済みのファイルはスキップされます。

この拡張機能を選ぶ理由

たいていの X 動画ダウンローダーはボタンが一つあるだけで、画質は向こう任せ、ファイルは video.mp4 のような名前でダウンロードフォルダに放り込まれ、次に保存したものが前のものを上書きしてしまいます。この拡張機能は、まさにその 3 点を解決するために作りました。

機能

• 動画・GIF・画像に対応 —— メディアを含む投稿のアクションバーにダウンロードアイコンが表示されます。X 本来のアイコンに合わせたデザインとサイズなので、後付け感がありません。画像投稿やリンクプレビューのカードにも対応しています。動画と画像の両方が入った投稿なら、ワンクリックですべて保存します。

• 画質を選べる —— 既定値（最高 / 1080p / 720p / 480p / 360p / 最低）を設定すると、その上限を超えない範囲で常に最良の画質を選びます。アイコンを右クリックすれば、その投稿に対して X が実際に配信している画質の一覧からその場で選べます。

• 重複コピーを作らない —— この拡張機能は保存済みの内容を覚えており、同じ動画が他人のリポストに出てきても判別します。もう一度クリックすると「ダウンロード済み」と表示され、「(1)」のコピーは作りません。さらにもう一度クリックすればそれでもダウンロードします。ファイルを削除済みなら、そのまま再ダウンロードします。

• アカウントごとにフォルダ —— 既定では Downloads/X Media Downloader/<アカウント>/ に保存されるので、アカウントごとのメディアがひとところにまとまります。フォルダ名を変更したり、ファイル名の変数をフォルダ名に使ったり、「毎回保存先を確認する」をオンにしてファイルごとに OS の「名前を付けて保存」ダイアログを出すこともできます。

• 重複しないファイル名 —— 既定のテンプレートは {user}_{text}_{datetime}_{id}。投稿者、本文の冒頭、投稿自体のタイムスタンプ、そして投稿 ID。内容がひと目で分かり、時系列に並び、誤って上書きされることもありません。

• 完全なダウンロード履歴 —— すべてのファイルがオプションページに記録されます。サムネイル、アカウント、画質、サイズ、日付、状態つき。検索、再ダウンロード、ファイルの場所を開く、履歴全体を JSON で書き出すこともできます。プロフィールのダウンロードは単独で表示できます。

• 複数画像の投稿は、すべての画像をオリジナル解像度で _1 〜 _4 の連番で保存します。

• あなたの言語で —— インターフェース全体がブラウザの言語に従います：英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語（スペインとラテンアメリカ）、ブラジルポルトガル語とアラビア語。

プライバシー

アカウント不要、サーバーなし、解析なし、トラッキングなし。すべてブラウザ内で完結し、ダウンロード履歴が端末の外に出ることはありません。通信するのは、指定されたメディアを取得するための X 自身のドメインだけです。
