# Promo poster renderer

Renders the localized "batch download" poster used as the first Chrome Web Store
screenshot (landscape 1280x800) and for README / social posts (portrait 1125x1400).

- `poster.html|css|js` — layout; text comes from `copy_<locale>.json` (one per `_locales` entry).
- `popup_harness.*` — loads the **real** `src/popup/` with a stubbed `chrome` API and
  synthetic data (a NASA post, 4 history entries), so the popup in the poster always
  matches the shipped UI and locale. `thumb.png` is the fake video poster.
- `scene.jpg` — background, generated by Codex image_gen (no text, no logos).

```bash
python tools/poster/serve.py            # http://localhost:8766, no-cache, repo root
bash tools/poster/render.sh <bsk-session> en zh_CN zh_TW ja ko es es_419 pt_BR ar
```

Render in a light-theme browser (the popup follows `prefers-color-scheme`). Output goes
to `tools/poster/out/` (git-ignored). The store needs 24-bit images, which `render.sh` writes.

New locale: add `copy_<locale>.json` with the same keys as `copy_en.json`.
